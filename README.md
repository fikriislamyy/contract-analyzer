# AI Contract Analyzer

Upload a contract PDF, get an AI-generated summary, flagged risk clauses,
and a chat interface for asking questions about the document.

## Stack
- **Backend:** FastAPI (Python 3.12), PyMuPDF, Gemini API
- **Frontend:** React + Vite + Tailwind
- **Hosting:** Render (API) + Vercel (client)
